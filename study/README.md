# Study Plans

Este directorio contiene dos planes de estudio prácticos, pensados para aplicarlos directamente sobre este repo:

- `java-puro-plan.md`: enfoque en lenguaje Java (sin depender de Spring para aprender conceptos).
- `spring-plan.md`: enfoque en capacidades específicas del ecosistema Spring.

Sugerencia de uso:

1. Sigue un plan a la vez.
2. Cierra cada semana con un mini entregable funcional.
3. No avances a la siguiente semana sin cumplir los criterios de "hecho".
